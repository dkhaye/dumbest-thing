# Security

This repository contains small demo programs and the scripts that record them.
It has no production deployment, no services, and handles no user data. Some of
the demos deliberately run code that misbehaves (that is the point), but only
locally and only on their own fixtures.

If you believe you've found a real security problem, such as a script that
does something unsafe when run, please use GitHub's
[private vulnerability reporting](https://github.com/dkhaye/dumbest-thing/security/advisories/new)
rather than opening a public issue. Reports are handled on a best-effort basis.
