# SQL

SQL demos for [The Dumbest Thing You Can Do in Every Programming Language](../README.md).

- `candidates/` — verified reproducers, each with its command, output, explanation, and sources.
- `final/` — the beats used in the talk.

Demos run via the `sqlite3` CLI for zero-setup reproducibility, but every
candidate here is standard ANSI SQL — the same result is confirmed against
real PostgreSQL where noted. The joke is "SQL is dumb," not "SQLite is dumb."
